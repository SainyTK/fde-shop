# FDE Shop

FDE Shop is a Shopee-style marketplace built for the FDE 101 Web e-commerce workshop.
Sellers list products and manage their stock, and buyers shop, apply coupons, pay and track their deliveries.

## Scope

1. Seller accounts
2. Buyer accounts
3. Discount coupons
4. Shipment tracking
5. Stock management for sellers
6. Payment slip check (optional)
